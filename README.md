# Ludo Educational Game

Team RABBIT — Software Engineering and Software Quality Assurance in Information Systems.

This repository contains Iteration 1 of an original Java Ludo game. The project uses Maven, Java 17, Swing, JUnit 5, and an MVC split across the packages `Model`, `View`, and `Controller`.

## Requirements

- JDK 17 or newer (the build targets Java 17)
- Maven 3.9 or newer

## Build

```powershell
mvn clean verify
```

## Run

```powershell
java -jar target/ludo-game-1.0-SNAPSHOT.jar
```

Feature details, the branch workflow, and the Iteration 1 test report are completed on the `integration/iteration-1` branch.
